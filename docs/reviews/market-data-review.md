## Issues

### Critical

- None found within this task scope.

### Important

1. **[P1] Advance the final freshness clock when `now_ms` is supplied.** `src/btc5m/market_data.py:590` reuses the caller's initial `now`, so the round check, final book checks, latest-price checks and returned `Snapshot.now_ms` ignore elapsed network work (`src/btc5m/market_data.py:591`, `src/btc5m/market_data.py:636`, `src/btc5m/market_data.py:646`). A focused fixture replay let both books finish, then advanced the UTC and monotonic clocks by four seconds before the last metadata response. `snapshot(now_ms=initial)` returned successfully with a **7,000 ms-old spot** under the **5,000 ms** limit; the identical `snapshot()` call rejected `STALE_DATA`. The first call returned `now_ms=1788711604000` while the actual clock was `1788711608000`. This public argument also freezes the final round-boundary check. Use an advancing time source for the final checks even when the initial instant is supplied, and add a targeted case covering elapsed metadata work with explicit `now_ms`. The current freshness cases never pass this argument (`tests/test_market_data.py:324`).

2. **[P1] Invalidate the current round when delayed official metadata reports changed rules.** `src/btc5m/market_data.py:513` detects changed descriptions or settlement source for a matching slug/condition, but `src/btc5m/market_data.py:527` only emits `metadata_unavailable`; it leaves the retained round eligible. If the subsequent raw Gamma response still contains the older cached supported description, `snapshot()` returns that round with its usable captured/official anchor. A focused replay supplied a matching official SDK event with a changed rule and fresh current feeds/books while keeping the raw discovery response at its earlier contents. It emitted `UNSUPPORTED_RULE` and then **returned the same current round with `reference_status='boundary'`**. This is a supported cached-response disagreement scenario, not a transient HTTP error: the adapter has observed an incompatible official rule for the selected contract. Mark that retained round incompatible/conflicted and block its entries persistently; keep ordinary network failures and missing optional anchor metadata retryable. The existing test checks only that a changed rule cannot supply an expired round's calibration label, so it misses this current-entry path (`tests/test_market_data.py:786`).

### Minor

3. **[P3] Make the empty-ask strategy assertion reach the intended gate.** `tests/test_market_data.py:405` asserts only `side is None` with the default fixture clock at start plus four seconds. That snapshot already returns `ENTRY_WINDOW`, independently of its empty asks, as the neighboring integration test demonstrates (`tests/test_market_data.py:410`). The assertion at line 404 correctly tests preservation, but the strategy assertion does not establish the claimed missing-book skip. Arrange otherwise eligible inputs and assert the relevant reason, or narrow this test to its actual preservation responsibility.
